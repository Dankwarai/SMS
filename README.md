# School Management System (SMS)

A full-featured school management web application frontend built with **Vanilla JavaScript**, **Vite**, **Tailwind CSS**, and **Chart.js**. Designed as a PWA with a modular component architecture.

## Features

- **Dashboard** — Overview stats, charts, and quick-access widgets
- **Students** — Student records, enrollment, profiles
- **Teachers** — Teacher management and assignments
- **Academics** — Courses, timetables, and academic management
- **Attendance** — Daily attendance tracking
- **CBT (Computer-Based Testing)** — Online exam and assessment module
- **Finance** — Fee management and financial reporting
- **Library** — Library resource management
- **Chat** — In-app messaging
- **Transport** — Transport route and vehicle management
- **Calendar** — Academic calendar and scheduling
- **AI Module** — AI-assisted features
- **Settings** — System configuration
- **PWA Support** — Installable on mobile and desktop

## Tech Stack

- **JavaScript** (ES Modules, Vanilla JS)
- **Vite** — Build tool and dev server
- **Tailwind CSS** — Utility-first styling
- **Chart.js** — Data visualisation
- **Vitest** — Unit testing

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Dankwarai/SMS.git
cd SMS

# Install dependencies
npm install

# Start development server
npm run dev

# Run tests
npm test

# Build for production
npm run build
```

## Project Structure

```
src/
├── components/     # Feature modules (Students, Teachers, Finance, etc.)
├── services/       # API service layer
├── assets/         # Images and static files
├── styles/         # CSS stylesheets
└── main.js         # App entry point
```
